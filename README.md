# 👋 About Me

I'm a **Senior Android Platform Engineer** focused on building scalable, secure, maintainable, and high-performance Android applications.

With **8+ years of Android engineering experience**, my core focus is modern Android development using **Kotlin, Jetpack Compose, Android Architecture Components, Clean Architecture, MVVM, Multi-Module Architecture, Offline-First Systems, and Performance Engineering**.

I enjoy solving complex mobile engineering problems—from architecture modernization and resilient data synchronization to performance optimization, secure mobile development, reusable UI systems, and CI/CD automation.

My current technical exploration includes **Kotlin Multiplatform, Compose Multiplatform, Gemini API, ML Kit, Baseline Profiles, Macrobenchmark, Perfetto, JankStats, Credential Manager, Play Integrity, Proto DataStore, and KSP**. These are learning/POC areas rather than claims of production experience. :contentReference[oaicite:1]{index=1}
