# 🏗️ Architecture Philosophy

I design Android applications around clear separation of responsibilities and predictable data flow.

```text
┌───────────────────────────┐
│       Presentation        │
│    Compose / UI State     │
└─────────────┬─────────────┘
              │
              ▼
┌───────────────────────────┐
│        ViewModel          │
│    State / UI Logic       │
└─────────────┬─────────────┘
              │
              ▼
┌───────────────────────────┐
│         Use Cases         │
│      Business Logic       │
└─────────────┬─────────────┘
              │
              ▼
┌───────────────────────────┐
│        Repository         │
└─────────────┬─────────────┘
              │
        ┌─────┴─────┐
        ▼           ▼
   ┌────────┐   ┌────────┐
   │  Room  │   │ Retrofit│
   └────────┘   └────────┘
        │           │
        └─────┬─────┘
              ▼
          Data Layer
```

### Core Principles

- Separation of concerns
- Dependency inversion
- Single responsibility
- Feature isolation
- Offline resilience
- Reactive state management
- Reusable components
- Performance-aware development
- Secure-by-design engineering
